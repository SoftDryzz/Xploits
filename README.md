# KitBot

Addon de Meteor Client (MC 1.21.11) con el módulo `KitRequester`: pide kits a SnifferBuddy en 6b6t en lotes de hasta 5, acepta la TPA del courier que los entrega y guarda el progreso para retomar tras un kick.

**Estado:** diseño aprobado, implementación pendiente.
